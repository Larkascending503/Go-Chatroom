# Go 聊天室

一个基于 Go 语言构建的简单 TCP 聊天室系统，支持多用户并发，具备广播消息、私聊等功能。

## 功能特性

- **群发消息** — 向所有在线用户发送消息
- **私聊消息** — 向指定用户发送私信
- **在线用户列表** — 查看当前所有在线用户
- **修改昵称** — 自定义显示名称
- **自动踢出** — 用户超过 60 秒无操作将被自动断开连接

## 项目结构

```
communication-system/
├── server/
│   ├── main.go       # 服务端入口
│   ├── server.go     # 服务端核心逻辑（TCP 监听、广播、连接处理）
│   └── user.go       # 用户结构体及消息处理（LIST、RENAME、PVT）
├── client/
│   └── client.go     # 客户端，带交互式菜单
├── go.mod
└── README_zh.md
```

## 快速开始

### 环境要求

- Go 1.26+

### 启动服务端

```bash
cd server
go run .
```

服务端默认监听 `127.0.0.1:8888`。

### 启动客户端

```bash
cd client
go run . -ip 127.0.0.1 -port 8888
```

#### 命令行参数

| 参数    | 默认值      | 说明           |
| ------- | ----------- | -------------- |
| `-ip`   | `127.0.0.1` | 服务器 IP 地址 |
| `-port` | `8888`      | 服务器端口     |

### 客户端菜单

连接成功后，客户端会显示交互式菜单：

```
1. 群聊   — 向所有用户发送消息
2. 私聊   — 向指定用户发送私信
3. 改名   — 修改用户名
0. 退出   — 断开连接并退出
```

## 使用示例

**群聊：** 选择 `1`，输入消息后按回车发送。输入 `exit` 返回菜单。

**私聊：** 选择 `2`，查看在线用户列表，输入目标用户名和消息内容。输入 `exit` 返回菜单。

**改名：** 选择 `3`，输入新的用户名即可。
